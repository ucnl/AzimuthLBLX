# Changelog — AzimuthLBLX

Все значимые изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).


## [0.2.1] - 2026-09-04

### Добавлено
- **PWA поддержка**:
  - `manifest.json` — манифест приложения (имя, иконки, тема, ориентация)
  - `sw.js` — Service Worker для офлайн-работы и кэширования
  - Иконки приложения: 192×192, 512×512, maskable 512×512
  - Регистрация Service Worker с проверкой протокола (не для `file://`)
- **Проверка поддержки Web Serial API**:
  - При отсутствии Web Serial API кнопка подключения блокируется
  - Информативное сообщение в статусной строке

### Изменено
- `index.html` — добавлены meta-теги для PWA и iOS
- `app.js`:
  - Добавлена регистрация Service Worker (только для https/localhost)
  - Добавлена проверка `navigator.serial`
  - Логирование режима запуска (file:// vs https)




## [0.2.0] — 2026-09-04

### Добавлено
- **Программирование LBL решателя** (`$PAZMA`):
  - Модальное окно для настройки параметров LBL навигационного решателя
  - Поля для ввода координат до 4 маяков (адрес, долгота, широта)
  - Кнопка «Из решений» — автоматическая подстановка координат из VLBL решений
  - Кнопка «Отправить» — формирование и отправка `$PAZMA` команды
  - Ожидание подтверждения от устройства с таймаутом 3 секунды
  - Обработка ACK ответов (`$PAZM0`) с кодами ошибок
- **Парсер `$PAZMA`** в `azm-parser.js`:
  - Разбор всех полей конфигурации LBL решателя
  - Поддержка опционального 4-го маяка
- **Билдер `$PAZMA`** в `azm-parser.js`:
  - Формирование команды с корректным пропуском пустых полей
  - Автоматический расчёт контрольной суммы NMEA
- **Настройки LBL решателя** в localStorage:
  - Автовывод NMEA (auto_output)
  - Автозапуск (autostart_on_poweron)
  - Солёность (salinity)
  - Скорость звука (sos)
  - Параметры фильтров (smflt, achod)
  - Порог ошибки решения (rerr_thld)

### Изменено
- Обновлена структура `AZMParser.SentenceType` — добавлен `LBP_SETA: 'A'`
- `VLBLManager` расширен методом `getLBP_SETACommand()`

## [0.1.0] — 2026-08-30

### Добавлено
- **VLBL Survey Tool** — базовый функционал:
  - Подключение к Zima2 USBL по Web Serial API
  - Приём данных от маяков-ответчиков (`$PAZM3`)
  - Расчёт наклонных дальностей и горизонтальных проекций
  - Сбор измерений для VLBL калибровки
  - Решение положения маяков методом наименьших квадратов (2D)
  - Web Worker для асинхронного решения без блокировки UI
- **Визуализация**:
  - Canvas карта с треком судна и позициями маяков
  - Авто-масштабирование
  - Линейка для измерения дистанций
  - POI (точки интереса)
- **Экспорт**:
  - CSV: трек судна, измерения, решения
  - KML: всё вместе
- **Логирование**:
  - Запись входящих/исходящих сообщений
  - Сохранение/загрузка логов
  - Воспроизведение логов с регулируемой скоростью
  - Анализ логов (статистика)
- **GNSS**:
  - Подключение внешнего GNSS через Web Serial
  - Парсинг RMC, HDT, HDG, HDM
  - Поддержка внутреннего GNSS (WebView API)
- **Эмуляция**:
  - Режим эмуляции для тестирования без реального оборудования
- **Темы оформления**:
  - Indoor (по умолчанию)
  - Light
  - Dark Contrast
  - Jack Black
  - Jack White
  - VAX (терминальный стиль)
- **Настройки**:
  - Маска адресов маяков
  - Максимальная дальность
  - Солёность
  - Скорость звука (авто/ручная)
  - Параметры VLBL базы
  - Авто-решение (интервал)
  - Скорость GNSS порта

### Исправлено
- Корректная обработка таймаутов маяков
- Расчёт глубины антенны из давления
- Расчёт скорости звука по температуре и солёности
